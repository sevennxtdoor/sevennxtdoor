## Hi, I'm Seven 👋

I'm from Indonesia and I'm learning C++ by building a Growtopia private server.

### 🌱 What I'm working on

**SevenPS** — a Growtopia private server built on [Gurotopia](https://github.com/gurotopia/Gurotopia), aiming to work like the real game.
- Guilds, mentors & apprentices, magplants, vending machines, storage boxes, fishing, surgery and more
- Token login page with hashed passwords, flood and anti-cheat guards
- An offline test suite that runs the server code against a local database

The repository is private for now.
